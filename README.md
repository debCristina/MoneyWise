## 🚀 Desenvolvimento

O desenvolvimento do projeto é organizado através de:

- Issues
- Branches
- Pull Requests
- Code Review

### Fluxo de desenvolvimento

1. Uma Issue é criada.
2. Uma branch é criada a partir da Issue.
3. O desenvolvimento é realizado.
4. São criados ou atualizados os testes.
5. Uma Pull Request é aberta.
6. Os colaboradores revisam o código.
7. Após aprovação, a Pull Request é integrada à branch principal.
